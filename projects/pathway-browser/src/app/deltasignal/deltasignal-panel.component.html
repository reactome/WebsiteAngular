What do these columns mean?
Predicted level
The entity's predicted level once the network settles, as a fold over its resting level: 1× is normal, 0× is gone, higher is more. It is read exactly the way DeltaSignal's published accuracy was measured: the entity resolves to the network's copies of it, each curated entity counts once (never once per internal copy), and a curated species the network only represents through its reactions is read from those reactions' flux.
Call
The direction at the validated thresholds @if (service.readoutState().protocol; as protocol) { (down below {{ protocol.down_cutoff }}×, up at {{ protocol.up_cutoff }}× or more) } — the same rule the benchmark figures used. Between the thresholds the model calls no change.
At the model's bound
Node levels live between hard stops @if (service.readoutState().protocol; as protocol) { @if (protocol.rail_low !== undefined && protocol.rail_high !== undefined) { ({{ protocol.rail_low }}× and {{ protocol.rail_high }}× here) } } — a prediction at a stop is a switch pushed to one side, not a measured magnitude. The direction call still stands, but read the number as "as far as the model can go", the same rule DeltaSignal's own validation record uses to set such values aside.
Influence
How strongly everything this entity feeds directly in the logic network (the reactions it is an input to, catalyses or regulates, a set it belongs to, and so on; the “Logic nodes & edges” view shows these links) responds to a small change in it, at the predicted state. It ranks direct, local effect, not effect on the whole pathway, and has no unit; an entity that feeds nothing scores 0.

Rows are sorted by how far the fold departs from 1×; a highlighted row is one you perturbed. These values come from the same readout service the benchmarks ran, not from averaging the table's rows in the browser.
