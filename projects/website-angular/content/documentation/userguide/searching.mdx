## Searching Reactome

See our Youtube Video explaining [Reactome's Main Search Feature](https://youtu.be/3lXWcPgP8iQ)!

## Simple text search

The simple text search tool is located top right of the Home page. To search, type a word, phrase or identifier in the search box. The search has an auto-complete function; if the text you wanted to use appears in the drop-down list, select it and results will be displayed. For other text click Search.

![Simple text search](/uploads/documentation/userguide/searching/searching-01-simple-text-search.png)

Search results are presented in categories with grey headers, representing the molecular entity or event types.

Below the header is a list of items from the named type that match your search terms. Matching words are highlighted in grey. Click on the name of an item to go to a page of details.

On the left side of the search results page are groups of checkboxes. These can be used to change defaults and add filters. Check or uncheck boxes for types that you do/don’t want to see, e.g. if you want to see results for Mus musculus, under Species uncheck Homo sapiens and check Mus musculus. In the Type, Compartment and Reaction Type filter groups, select to only see results that fall into the selected category, e.g. to see only reactions, select Reaction in the Types filter group. To see only Reactions that occur in the cytosol, also select Cytosol in Compartments.

![Simple text search](/uploads/documentation/userguide/searching/searching-02-simple-text-search.png)

Click on any of the results to go to a page of information about it. The contents of these Results Detail pages will depend on the type, but all have a section named ‘Locations in the PathwayBrowser’.

![Simple text search](/uploads/documentation/userguide/searching/searching-03-simple-text-search.png)

This contains an expandable hierarchy that identifies the locations of the item in Reactome pathway diagrams. Click the plus symbol to open the hierarchy.

This hierarchy reflects the organization of events in Reactome. ‘Top-level’ pathways representing a broad area of biology typically contain one or more levels of subpathways, becoming more specific with each level. The levels of the hierarchy are represented here by indentation; the most general pathways are closest to the left-hand edge of the screen, the most specific subpathways have the greatest indentation to the right. Note that some search result items (e.g. proteins) can be in more than one pathway, which may be in different broad areas of biology, resulting in representation in multiple hierarchies. Note that you can open all the hierarchy levels with a single click on the Expand all link, on the right side. Select any event name to open the corresponding Pathway Diagram. The diagram will open with an animation that shows you where the pathway is located in the Pathway Overview. If the selected item was an event it will be highlighted in blue in the Pathway Diagram. If it was a protein, all instances of it will be highlighted in pink.

**Icon Search**

Elements of the Icon Library are accessible to the main website search. In the screenshot below, the results of a search for the term: "liver" are displayed.

![Icon Search](/uploads/documentation/userguide/searching/searching-04-icon-search.png)

Below the header is a list of items from the "icon" type that match the "liver" search term. Matching words are highlighted in grey. Click on the name of an item to go to a page of details. In the following image, selecting the first search result is shown

![Icon Search](/uploads/documentation/userguide/searching/searching-05-icon-search.png)

The metadata associated with the selected icon is displayed, including the icon category, the curator and designer, and a brief description of the icon. To download the image icon files, click the links to the right of the preview image. Further down the page is a series of expandable hierarchy links that identifies the locations of the icon in Reactome pathway diagrams. Click the plus symbol to open the hierarchy. Clicking the external link, towards the bottom of the page, will link out to the referencing database for the named icon.

**Searching in the Pathway Browser**

Searches can be performed within the Pathway Browser using the In-Diagram Search panel (top left corner of the Event Hierarchy Panel). If no pathways have been selected, all of Reactome is searched.

![Searching in the Pathway Browser](/uploads/documentation/userguide/searching/searching-06-searching-in-the-pathway-browser.png)

In the example below, as the search term, ‘IL6’ has been entered. The search tool has predicted results that match this search term and displays a drop-down list of these matches.

![Searching in the Pathway Browser](/uploads/documentation/userguide/searching/searching-07-searching-in-the-pathway-browser.png)

By default, this search displays all of the pathways containing the search term, in a scrollable list, accompanied by an icon representing the type of molecule or event. The search results can be filtered by:

- Reaction
- Complex
- Pathway
- Set
- Protein
- DNA Sequence.

![Searching in the Pathway Browser](/uploads/documentation/userguide/searching/searching-08-searching-in-the-pathway-browser.png)

Selecting a molecule in the Search Results Panel reveals a side-panel to appear, showing the pathways where the molecule is available. Selecting an item in the Search Results panel causes the pathway diagram to zoom and recentre, focusing on the region containing the selected item. This identifies the selected item and lists the pathways that contain the selected item.

![Searching in the Pathway Browser](/uploads/documentation/userguide/searching/searching-09-searching-in-the-pathway-browser.png)

![Sample image showing IL6 Gene in the “Senescence-Associated Secretory Phenotype (SASP)” pathway.](/uploads/documentation/userguide/searching/searching-10-il6-gene-in-the-senescence-associated.png)

_Sample image showing IL6 Gene in the “Senescence-Associated Secretory Phenotype (SASP)” pathway._

Clicking on the "Flag" icon button in the Search Results Details Panel highlights events that contain the selected molecule in magenta. Clicking the "Flag" button for a second time will remove the highlighting.

![Searching in the Pathway Browser](/uploads/documentation/userguide/searching/searching-11-searching-in-the-pathway-browser.png)
