##  Is there a way to download high level images which can be zoomed in locally (after download)? 

If you would like to download icons and Enhanced High Level Diagrams(EHLD), yes, we provide SVG format for both. Please visit our icon library [here](</icon-lib>), you can download any EHLDs in pathway browser by clicking the download button at the top right corner to export diagram to different formats including SVG.

However, if you would like to download a high level image of Reacfoam, unfortunately, there is no way to export it for now, basically, it takes a screenshot of the current window when you download a Reacfoam image.
