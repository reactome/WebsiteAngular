##  Linking to us 

Reciprocal linking between related bioinformatics resources not only encourages mutual traffic but ensures that Reactome users can quickly linkout to the source reference material as they navigate through our website. Furthermore, many Reactome visitors are referred to this web site by many bioinformatics resources that integrate Reactome data. These resources include UniProt, Genecards, OMIM, NCBI Biosystems, MSigDB, HGNC, NextProt, BioGPS, Pathway Commons, and Wikipathways.

Our goal with distributing different sets of files for each identifier type (i.e. protein ([UniProt](<https://www.uniprot.org>)), gene (Ensembl and NCBI), small molecule (ChEBI), and microRNA (miRBase)) is to link the source database identifier to: 

  1. the lowest level pathway diagram or subset of the pathway,
  2. all level pathway diagrams, and all reaction events.

The identifier mapping files can be obtained from our [Downloads](</download-data>) section.

An alternative strategy to link to Reactome can be achieved by creating URLs containing the name of and an identifier from an “external” database in the following format: [_https://reactome.org/content/query?cluster=true &q=identifier_](<https://reactome.org/content/query?cluster=true&q=identifier>) _._

Click [here](</documentation/linking-to-us/identifiers>) to see the external databases and list of identifiers available in the current release of Reactome

Below are few concrete examples:

  * [UniProt](<https://www.uniprot.org/>) accession numbers (the ‘AC’ line, preferred) and identifiers (the ‘ID’ line), e.g. UNIPROT:P30304, [https://reactome.org/content/query?cluster=true&q=P30304](<https://reactome.org/content/query?cluster=true&q=P30304>)
  * [ChEBI](<https://www.ebi.ac.uk/chebi/>) identifiers, e.g. CHEBI:15422, [https://reactome.org/content/query?cluster=true&q=15422](<https://reactome.org/content/query?cluster=true&q=15422>)
  * [COMPOUND](<http://www.genome.jp/kegg/compound/>) identifiers, e.g. COMPOUND:C00002, [https://reactome.org/content/query?cluster=true&q=C00002](<https://reactome.org/content/query?cluster=true&q=C00002>)
  * [Gene Ontology](<http://www.geneontology.org/>) (GO) accession numbers, e.g. GO:0030060, [https://reactome.org/content/query?cluster=true&q=0030060](<https://reactome.org/content/query?cluster=true&q=0030060>)
  * [Enzyme Classification](<https://www.brenda-enzymes.info/index.php>) (EC) numbers, e.g. EC:1.1.1.37, [https://reactome.org/content/query?cluster=true&q=1.1.1.37](<https://reactome.org/content/query?cluster=true&q=1.1.1.37>)
  * [NCBI Gene](<https://www.ncbi.nlm.nih.gov/gene>), e.g. NCBI Gene:4171, [https://reactome.org/content/query?cluster=true&q=4171](<https://reactome.org/content/query?cluster=true&q=4171>)
