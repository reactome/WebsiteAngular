# Contract: the checks, and how each is shown failing

Constitution III: no check is trusted until it has been seen red. Each row names the breakage that must turn it red; the task that adds the check records, in `tasks.md`, that it did.

All service checks run in vitest against the stub ORCID (T006) on the loopback interface, with the graph reads replaced as the person specs replace them, and the claim-record sender and the clock injected. Site checks run in Playwright with `/ContentService/orcid/**` answered by the test (`page.route`), the way `e2e/support/backend.ts` answers recordings, and the stub's authorise page.
