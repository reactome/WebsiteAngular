# Data model: SBML and BioPAX built from the graph

What BioPAX3Exporter must write (spec FR-005), and where each value is in the graph. It reads the graph through graph-core's objects, whose names are used below (as in `tools/content-node/domain-snapshot.json`).

## Entities

- **Event**: a Pathway or a ReactionLikeEvent, asked for by stable id (any version) or dbId, as `resolveId` reads one. Not found is a 404. An object that is not an event is a 400, decided from its labels.
- **SBML document**: one per event.
  - **Model:** the event, or for a reaction its first parent pathway by `hasEvent.order`.
  - **Compartments, species and reactions:** from the reference converter's two queries, in their row order.
  - **Annotations:** notes, History and CVTerms.
  - **Layout:** optional (below).
- **Layout**: present only when the event has its own diagram that draws at least one reaction. Built from that diagram's JSON. It also sets the drawn species' SBO terms and the layout namespace on the root.
- **Diagram**: `diagram/{stId}.json` of the same release. Its parts:
  - **nodes:** `prop` for the box, `textPosition`, `renderableClass`, `reactomeId`, `connectors`;
  - **edges:** `position`, `segments`, and `inputs`/`outputs`/`catalysts`/`activators`/`inhibitors`, each a target id with its branch points;
  - **compartments.**
- **BioPAX document**: one per event. RDF/XML. Individuals carry `rdf:ID="{Class}{n}"` and are written in a deterministic order. `xml:base` is `http://www.reactome.org/biopax/{release}/{topDbId}#`.
- **Reference answer**: what each export is compared with:
  - SBML's model: the corrected graph-only converter's file, exactly;
  - SBML's layout: today's file (structure exactly, coordinates by meaning);
  - BioPAX: today's file, canonicalised.
- **Accepted difference**: a way the new output differs from its reference, with the reason, recorded in [contracts/differences.md](contracts/differences.md). An export switches only when every difference found is in that record.

The graph lacks three things today's converter reads:

- EC numbers beyond one per molecular function;
- book chapter authors;
- sequence domains, which no sample used.

The first two are recorded differences.

## Validation rules (from the requirements)

- **SBML:** byte-identical to the reference apart from the layout, the SBO terms the layout sets, the root's `layout:required` and layout namespace, and the generation note (FR-002). The layout has the same glyphs, ids, roles and order as today's (FR-003). libSBML reports 0 errors (FR-008).
- **BioPAX:** the canonical triples equal today's, apart from recorded differences (FR-005). The BioPAX validator reports 0 errors (FR-008).
