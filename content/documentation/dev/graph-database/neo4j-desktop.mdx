### Introduction

This article is going to describe step by step how to import our great Graph Database dump file into Neo4j Desktop

### Download

  * [Neo4j Desktop](<https://neo4j.com/download/>)
  * [Graph Database Dump file](</download/current/reactome.graphdb.dump>)

### Neo4j Desktop

Install Neo4j Desktop following the [official documentation website](<https://neo4j.com/docs/desktop-manual/current/installation/#download-installation>).

### Importing Graph Database

  1. Create new Project 

![neo4j desktop guide 1](/uploads/documentation/dev/graph-database/neo4j-desktop/neo4j_desktop_guide_1.png)

  2. Add reactome.graphdb.dump 

![neo4j desktop guide 3](/uploads/documentation/dev/graph-database/neo4j-desktop/neo4j_desktop_guide_3.png)

  3. Click on the Open button next to the file you have added and select "Create new DBMS from Dump". 

![neo4j desktop guide 7](/uploads/documentation/dev/graph-database/neo4j-desktop/neo4j_desktop_guide_7.png)

  4. Choose a name, password and version (preferably >4.x.x) 

![neo4j desktop guide 8](/uploads/documentation/dev/graph-database/neo4j-desktop/neo4j_desktop_guide_8.png)

  5. Not mandatory, open Neo4j Settings, edit "dbms.allow_upgrade=true
     1. This step is only needed if you are using Reactome Graph Database which is not compatible with v4.X.X. 

![neo4j desktop guide 9](/uploads/documentation/dev/graph-database/neo4j-desktop/neo4j_desktop_guide_9.png)

![neo4j desktop guide 10](/uploads/documentation/dev/graph-database/neo4j-desktop/neo4j_desktop_guide_10.png)

  6. Now Click on `Start` and you are ready to explore the Neo4j Browser or Neo4j Bloom. <http://localhost:7474>

![neo4j desktop guide 17](/uploads/documentation/dev/graph-database/neo4j-desktop/neo4j_desktop_guide_17.png)

### Adding a different version of the Reactome database

* Only Neo4j >4.x supports multiple DMBS, make sure you installed Neo4j 4.x.x

  1. Add reactome.previous.graphdb.dump 

![neo4j desktop guide 3](/uploads/documentation/dev/graph-database/neo4j-desktop/neo4j_desktop_guide_3.png)

  2. Click on the Open button next to the file you have added and select "Import dump into existing DBMS".
  3. Select Reactome and create database "reactome"

![neo4j desktop guide 16](/uploads/documentation/dev/graph-database/neo4j-desktop/neo4j_desktop_guide_16.png)

  1. Open Neo4j Settings 

![neo4j desktop guide 9](/uploads/documentation/dev/graph-database/neo4j-desktop/neo4j_desktop_guide_9.png)

  2. Not mandatory, open Neo4j Settings, edit "dbms.allow_upgrade=true  

     1. This step is only needed if you are using Reactome Graph Database which is not compatible with v4.X.X.

![neo4j desktop guide 10](/uploads/documentation/dev/graph-database/neo4j-desktop/neo4j_desktop_guide_10.png)

  3. If you want this database to be your default, then use its name in the settings file. 

![neo4j desktop guide 15](/uploads/documentation/dev/graph-database/neo4j-desktop/neo4j_desktop_guide_15.png)

  4. Now Click on `Start` and you are ready to explore the Neo4j Browser or Neo4j Bloom.
     1. <http://localhost:7474>
